'없음'이 아닌 '미확인'으로 관리합니다. 실제 후지를 확인한 뒤 정리하세요.

v2에 이미 들어 있던 항목은 중복 생성하지 않습니다.
기존 DB에서는 은무지 황박이 220인 경우에만 210으로 정정하며
나머지 사용자 수정값과 롤 저장 길이는 유지합니다.
기존 v2의 미확인 후지 두 항목은 충돌이 없을 때만 이름을 옮깁니다.

설치/업데이트:
HTTPS 정적 호스팅에 파일을 같은 경로로 교체한 뒤 갤럭시 Chrome에서
접속하세요. 기존 사이트의 브라우저 데이터를 삭제하지 마세요.
데이터는 해당 사이트의 IndexedDB에 저장됩니다.
업데이트 전 JSON 백업을 권장합니다.
엑셀은 보고용, JSON은 전체 복원용입니다.

[v5 UI 개선]
- 현재 재고 박스를 DB 원단 기본값 박스 위로 이동
- 롤 전체 지름을 입력/수정할 때 잔량 즉시 자동 계산
- 계산 버튼 제거
- 계산 결과를 최종 저장 재고 입력칸에 자동 반영
- 최종 저장 재고는 수동 보정 가능
- 지름이 비어 있거나 지관보다 작으면 저장 방지
- 기존 원단 마스터, 롤 재고, 백업 및 엑셀 기능 유지
- 기존 DB 구조 변경 없음. 같은 사이트의 IndexedDB를 그대로 사용

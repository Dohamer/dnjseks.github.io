[v5 UI 개선]
- 현재 재고 박스를 DB 원단 기본값 박스 위로 이동
- 롤 전체 지름을 입력/수정할 때 잔량 즉시 자동 계산
- 계산 버튼 제거
- 계산 결과를 최종 저장 재고 입력칸에 자동 반영
- 최종 저장 재고는 수동 보정 가능
- 지름이 비어 있거나 지관보다 작으면 저장 방지
- 기존 원단 마스터, 롤 재고, 백업 및 엑셀 기능 유지
- 기존 DB 구조 변경 없음. 같은 사이트의 IndexedDB를 그대로 사용

[v7 층별 재고 및 보고서]
- 롤마다 보관 층(3층/4층/미지정)을 저장하고 수정 가능
- 기존 롤은 임의로 층을 배정하지 않고 미지정으로 취급
- 원단별 현재 재고의 층 필터 및 전체 재고 현황
- 전체 재고는 원단명순 / 길이 긴 순 / 길이 짧은 순 정렬
- 원단+폭 합계는 분류+원단명+폭 기준으로 후지를 합산
- 후지별 내역과 롤별 내역은 별도로 유지
- 엑셀 시트: 요약, 원단폭합계, 3층, 4층, 미지정, 롤재고, 원단마스터
- 집계는 롤재고를 참조하는 SUMIFS/COUNTIFS 수식과 저장된 캐시값 사용
- 모든 엑셀 수정 시간은 Asia/Seoul 기준. UTC ISO 값은 +9시간으로 표시
- 과거 시간대 정보 없는 문자열은 한국 현지시각으로 해석
- 데이터 저장소 이름/기존 롤 ID/마스터 및 기존 재고값 유지
- JSON 백업/복원에 floor 필드 포함. 기존 백업의 floor 누락은 미지정으로 취급
- 새 데이터 저장 시각은 ISO UTC로 보관하고 보고할 때만 KST 변환

배포: 같은 GitHub Pages 주소의 기존 파일을 교체하세요.
업데이트 전 JSON 백업을 받으세요. 브라우저 사이트 데이터는 삭제하지 마세요.


[v8 미지정 재고 일괄 이동]
전체 원단의 미지정 재고를 3층으로 한 번에 변경합니다.
원단 선택/폭/후지 필터에 관계없이 전체 DB를 대상으로 합니다.
실행 전 대상 롤 수와 총 길이를 확인할 수 있습니다.
확인 버튼을 누르면 전체 마스터와 롤의 JSON 백업을 먼저 다운로드합니다.
그 후 하나의 IndexedDB readwrite 트랜잭션에서 floor만 3층으로 변경합니다.
기존 롤 ID, 저장 재고, 원단 규격, 메모, 수정일은 변경하지 않습니다.
이미 3층/4층으로 지정된 롤은 변경하지 않습니다.
기존 데이터의 floor 누락은 미지정으로 취급합니다.
같은 GitHub Pages 주소에 파일을 교체하고 사이트 데이터를 삭제하지 마세요.


[v9 엑셀형 재고 목록 및 선택 이동]
- 전체 DB의 롤을 행 단위로 표시 (원단명, 폭, 후지, 롤번호, 길이, 층)
- 3층/4층/미지정/전체 필터, 원단명·후지·폭 검색, 이름/길이 정렬
- 체크박스 또는 행 전체를 누르면 선택/해제. 키보드 Enter/Space 지원
- 현재 검색·층 필터에 보이는 목록 전체 선택 및 선택 해제
- 검색/정렬/층 필터를 바꿔도 기존 선택 유지
- 도착 층을 3층/4층/미지정 중 선택하여 선택한 롤만 이동
- 이미 도착 층에 있는 롤은 제외하고 확인 화면에 대상 개수/총 길이 표시
- 이동 전 전체 JSON 백업 생성, 원본 롤 ID/길이/규격/메모/수정일 유지
- 하나의 IndexedDB 트랜잭션으로 층 필드만 변경
- 기존 v8의 미지정→3층 고정 버튼을 선택형 재고 목록으로 대체
- 기존 원단 선택, 등록/수정, 전체 합계, 엑셀, JSON 백업·복원 유지
- 기존 DB 스키마와 데이터 저장소 변경 없음

설치: 압축 안의 파일을 기존 GitHub Pages 저장소 최상위에 덮어쓰기.
업데이트 전 JSON 백업을 받고 기존 사이트 데이터는 삭제하지 마세요.

원단 재고관리 Mobile PWA v1

- 갤럭시/Chrome용 오프라인 웹앱(PWA)
- 데이터는 휴대폰 IndexedDB에만 저장
- 현재까지 측정한 원단 두께 초기값 포함
- 지관 기본값 90mm
- 원단 + 후지 + 폭별 롤 재고 관리
- 새 롤 / 사용중 롤 등록
- 롤 전체 지름으로 잔량 계산
- 엑셀(.xlsx) 내보내기
- JSON 전체 백업 / 복원

설치 주의
PWA 설치 및 오프라인 기능은 HTTPS 또는 localhost에서 동작합니다.
이 폴더를 GitHub Pages, Netlify, Cloudflare Pages 같은 정적 호스팅에 올린 뒤
갤럭시 Chrome에서 접속해서 '홈 화면에 추가'하면 앱처럼 사용할 수 있습니다.

데이터 주의
Chrome의 사이트 데이터/앱 데이터를 삭제하면 IndexedDB도 지워질 수 있습니다.
휴대폰 변경이나 초기화 전에는 반드시 JSON 백업을 저장하세요.

현재 '한 롤 최대길이'는 실측값이 아직 없어서 기본 미설정입니다.
새 롤 등록 전에 각 원단 기본값에서 최대길이를 입력하면 됩니다.
